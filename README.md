# Hygelis: company story walkthrough (DES530)

Open `index.html` in Chrome, Edge or Safari. It works offline, straight from the folder; no server is needed.

- Move step by step with the **Next →** button, the ← → keys, or by scrolling. The top bar shows the current step (of 16) and roughly how much time is left.
- The four films play one at a time. **CC captions** switches on subtitles made from the voiceover.
- Persona cards open full size with "Open full card ↗".

Folder layout (as the project handoff recommends):

```
index.html
css/styles.css
js/app.js, js/captions.js
assets/videos/   four films + .vtt captions
assets/posters/  film poster frames
assets/personas/ avatars + full persona cards
assets/dashboard/ the canonical Hygelis Signal dashboard
assets/logo/     logo + favicons
assets/fonts/    Inter (SIL Open Font License)
references/sources.md
```
